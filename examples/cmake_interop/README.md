# CMake → Ninja → PMake

Demonstrates using PMake to build a CMake-generated project.

## Setup

```bash
cmake -G Ninja -S . -B build -DCMAKE_BUILD_TYPE=Release
```

## Build with PMake

```bash
pmake -f build/build.ninja
```

Equivalent to:

```bash
ninja -C build
```

## Build with Ninja (for comparison)

```bash
ninja -C build
```

## Known limitations

- `compile_commands.json` is not generated by PMake (yet — see
  [docs/ROADMAP.md](../../docs/ROADMAP.md), v1.3.1)
- `dyndep` (C++20 modules) is not supported
- Implicit outputs (`|` before `:`) are ignored
